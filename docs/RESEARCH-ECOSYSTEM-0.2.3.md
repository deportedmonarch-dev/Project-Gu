# External ecosystem research — 2026-11

## Anima Expansion (Steam 3532147582)
- RimWorld 1.6/1.7; requires Royalty and Bunny Framework.
- Strong ecology/visual inspiration. No code dependency is added to Project GU.
- Our targeted ecology: spirit spring -> moon orchid habitats -> Hope Gu recovery -> awakenings -> cultivators -> Gu economy. Habitat markers are a test representation, not growing plants.

## Epochs - Golems (Steam 3609646528)
- Workshop currently lists 1.6 only; requires Tabula Rasa and Asimov.
- Golems act animal-like, need sleep but not food; work by skill. Author says CE compatibility not yet present.
- Intended future interpretation: artificial constructs powered by Gu (e.g., enslavement/formation paths), optional adapter only after 1.7 viability confirmed. Do not make this core dependency.

## Underground maps
- Preferred optional adapter: Strata (1.7, modder API with linked maps), subject to practical save/load and transfer profiling. Its full-size multi-level maps can be expensive and require care.
- DeepAndDeeeper (MIT source, older underground mechanics) remains a contingency and code-reference candidate. Do not mix two engines as authoritative providers.
- Gu spirit springs remain valid on normal surface maps even without either mod.

## Ideology
