# Project GU: Progression Scenarios (design only)

Scenarios must be data-driven presets, not divergent progression logic. Their initial conditions feed the same Core rules and preserve player agency.

Candidate presets:
1. **Mortal Household** — unawakened family, fields, food reserves, taxation, limited knowledge.
2. **Academy Intake** — young aspirants, scheduled lessons, examination and awakening access, clan patronage.
3. **Lesser Clan** — local spirit spring, treasury, elders, mortal villages and faction obligations.
4. **Wandering Gu Master** — few possessions, scarce stones, self-directed travel and trade.
5. **Caravan Syndicate** — merchandise, pack animals, temporary encampment, regional markets.
6. **Outcast / Demonic Cultivator** — hostile reputation, black-market contacts, risky cultivation opportunities.
7. **Variant-human Settlement** — species/faction content provided by optional add-ons.

Later integrate Progression: Scenarios if its API/version/license support it. All scenario definitions should avoid requiring an external mod to load a saved campaign. Scenario modifiers belong in save data with stable versioned keys.
