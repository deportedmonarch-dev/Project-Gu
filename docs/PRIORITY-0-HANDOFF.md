## Architecture and implementation state

| Component | Implemented at the checkpoint | Remaining scope |
|---|---|---|
| Engine ownership | Newly placed spring entrances use the independent provider via `independentOwner` in `Defs/MapGeneration/GU_SpiritSpringCavern.xml`. First entry materializes one `GuUndergroundLevelParent` and one native map per level. The parent saves a level ID and generator Def. The native save graph owns the map, terrain, Things, Pawns and nested inventories. | Current generated content is the existing spring profile. Additional site types and depth-generation rules are future work. |
| Addresses | `GuUndergroundAddressLayer` lazily registers one shared, hidden, disconnected 32-tile layer. It allocates an unused native address and uses the Core Underground biome. The independent fixture limit is eight loaded levels. The geographic surface tile is stored separately. The layer has pre-mutation teardown protection. | Benchmark further levels before changing the loaded-map limit. Loaded levels participate in native ticking. Dormancy and snapshots are outside this assignment. |
| Site, level and route graph | `GuIndependentSite.cs` holds separate stable IDs. The registry saves graph records under `guIndependentUndergroundSitesV1`. Missing endpoint bindings close travel. A generated level with an unresolved parent or map stays closed and is never regenerated. The isolated graph fixture exercises a three-level path and alternate exits. | The production entry point creates a single spring level. Deliberately rebinding a replacement entrance for a sealed unoccupied site is a future action. |
| Legacy native pockets | Existing saves and the generic probe use `guPocketProbeSitesV1`. Their native parent and source references are retained. The Harmony guards block ordinary source abandonment, automatic source removal and direct native pocket teardown when the source is still a dependency. Unused pending entrances do not pin the source. | The fixtures exercise the same native provider and persisted schema. A backed-up owner-era save still needs a rendered spot check. Saves already missing their native source have no general repair workflow in this branch. |
| Abandonment and world transitions | Removing an empty independent site's surface source closes its route while retaining the map and its physical contents. Guards block removal that would strand protected occupants. Ideology reset preflights protected underground contents or legacy dependencies. Odyssey unanchored launch and abandonment entry points check relevant dependencies before destructive mutation. | The full player-driven Archonexus UI and anchored gravship flight are outside the automated fixture. Third-party teardown paths that bypass the verified entry points remain unqualified. |
| Pawn and item recovery | The travel job revalidates the route and landing before moving the same Pawn and restores the origin after a rejected transfer. Emergency return moves that Pawn to a safe surface landing or creates an actual caravan at the recorded passable surface tile. Carried items move to the Pawn's inventory through native ThingOwner APIs. Equipment and existing inventory stay with that Pawn. | A carried Pawn is put down and recovered separately. Future persistent Gu custodians can expose protection through `IGuUndergroundCustodyProtection`. No individual Gu custody system was added. |
| Failed generation and retirement | A rejected attempt can discard only its own fixture map after checking for known Things, Pawns and child pockets. A retry becomes available after native removal and disposal have completed. All materialized spring and legacy probe sites currently use retention. | Deliberate retirement for a future eligible site type is planned. Uncertain cleanup remains closed for diagnosis. |
